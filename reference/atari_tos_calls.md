## AES / VDI (TRAP #2)

D0 = 200 ($C8): AES call, D1 = AES parameter block; D0 = 115 ($73): VDI call, D1 = VDI parameter block.

| $A00E | CopyRaster | copy raster form |
| $A00F | SeedFill | seed fill |
