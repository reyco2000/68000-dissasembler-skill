Generated by `python3 tools/macsyms.py --markdown hardware` from `tools/macsyms.py`.
Register spacing: VIA and IWM registers are $200 apart (VIA on the upper data
byte at even addresses, IWM on the lower byte at odd addresses); SCC channels
are 2 apart from separate read ($9FFFF8) and write ($BFFFF9) bases; Mac Plus
SCSI registers are $10 apart. ROM code usually loads a base from low memory
(`MOVEA.L (VIA).W,A1`) and uses offsets (`$1C00(A1)` = vIER).
